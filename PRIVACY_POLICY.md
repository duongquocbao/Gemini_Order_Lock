# Privacy Policy for Gemini & Notebook Order Extension

**Last updated:** October 03, 2026

This Privacy Policy applies to the "Gemini & Notebook Order" browser extension ("the Extension").

## 1. Information Collection and Use
The Extension does not collect, store, transmit, or share any of your personal information, browsing history, or notebook content. 

## 2. Local Storage
The Extension uses the browser's local storage API (`chrome.storage.local`) strictly to save the custom text tags you create for your notebooks. This data is stored entirely locally on your device and never leaves your browser. 

## 3. Remote Code and Tracking
The Extension does not use any remote code, tracking scripts, or analytics tools. It operates entirely within the context of the Google Gemini and NotebookLM webpages to organize the user interface.

## 4. Changes to This Policy
If there are any changes to this Privacy Policy in the future, the updated version will be posted here on our GitHub repository.

## 5. Contact
If you have any questions about this Privacy Policy, please open an issue in this GitHub repository.
